# Менеджер паролей

Лабораторная работа Б1. Программа хранит логины и пароли в JSON-файле.
Мастер-пароль проверяется через PBKDF2-HMAC-SHA256 со случайной солью
(600 000 итераций). В файл записывается SHA-256 от полученного ключа,
а сам ключ используется для симметричного шифрования паролей через Fernet.
Название сервиса и логин хранятся открыто. Ввод паролей скрыт через `getpass`.

Нужны Python 3.11+ и uv. Зависимости устанавливаются при первом запуске.

```bash
uv run python -m password_manager --init
uv run python -m password_manager --unlock
uv run python -m password_manager --generate
```

Без аргументов программа создаёт мастер-пароль при первом запуске,
а при повторном запрашивает его. Повторный `--init` отклоняется.
По умолчанию используется `passwords.json` в текущем каталоге;
другой путь можно указать через `--file vault.json`.

После входа доступны команды:

- `add` — запросить название, логин и пароль, добавить запись;
- `list` — показать только названия;
- `get <name>` — после повторного ввода мастер-пароля показать логин и пароль;
- `delete <name>` — удалить запись;
- `exit` — выйти.

Названия могут содержать пробелы. Повторное добавление существующего названия
отклоняется. Неверное подтверждение мастер-пароля завершает сеанс.
Сгенерированный пароль содержит 20 символов: строчные и заглавные буквы,
цифры и специальные символы. Забытый мастер-пароль восстановить нельзя.

Проверки:

```bash
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy --strict password_manager tests
```

Эти же проверки выполняются в GitHub Actions на каждый push и pull request.

Код разделён по назначению:

- `cli.py` — ввод пользователя и меню;
- `manager.py` — вход и операции с записями;
- `storage.py` — структуры данных, проверка, чтение и запись JSON;
- `security.py` — получение ключа, проверка хэша и создание шифра Fernet;
- `generator.py` — генерация паролей.

`PasswordManager` вызывает функции хранения и криптографии. Эти модули
не зависят от меню. `Vault` содержит данные файла, `Entry` — одну запись.
Ключ шифрования остаётся только в памяти открытого менеджера.
